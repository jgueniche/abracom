École → **Communauté** réunit ce que les familles s'échangent entre elles.

**L'annuaire** est entièrement volontaire : par défaut, vous n'y partagez **rien**. Dans « Ce que je partage », vous cochez ligne par ligne ce que les autres familles de la classe verront — téléphone, courriel, prénoms des enfants, adresse — et, si vous le souhaitez, les anniversaires de vos enfants, annoncés aux familles de la classe trois jours avant. Vous pouvez tout décocher à tout moment.

**Les petites annonces** couvrent le covoiturage, la garde partagée, les objets trouvés, les recommandations, les dons et les prêts.

:::roles parent, teacher, staff, school_admin, super_admin
Une annonce que vous déposez est **relue par l'école avant d'être publiée** : elle n'apparaît pas immédiatement. Une case permet d'y joindre les coordonnées que vous avez déjà choisi de partager dans l'annuaire, plutôt que de les retaper dans le texte.
:::

:::roles guardian
Vous lisez les annonces des autres familles. Le dépôt d'une annonce est réservé aux comptes qui peuvent écrire : votre accès est en lecture seule.
:::

Les anniversaires à venir des trente prochains jours s'affichent sur la page, pour les familles qui ont accepté de les partager.
